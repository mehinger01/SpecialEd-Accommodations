# Parser Workflow

## Current State
Parser V1 is operational.

## Workflow
1. Upload PDF
2. Parse document
3. Extract student data
4. Extract accommodations
5. Store parser result
6. Review queue
7. Approve or reject
8. Create/update student
9. Create/update accommodations
10. Audit event

## Current Priority
Fix student creation/update after successful parse.

## Rules
- Human review required
- Audit all approvals
- Preserve original extracted text
