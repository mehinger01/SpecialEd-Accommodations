# Fix 1: Full Universal Tools Title Extraction

## Current Incorrect Output

```text
supervision - Special education setting (NE)
```

## Required Output

```text
Universal Tools: Administration of the assessment in an alternate education setting (in school) with appropriate supervision - Special education setting (NE)
```

## Root Cause

The accommodation title wraps across multiple lines before the Start Date field.

The parser is currently capturing only the final line before Start Date.

## Required Behavior

For each accommodation block:

1. Locate Start Date.
2. Collect all title lines immediately preceding Start Date.
3. Stop when reaching:

   * a category header
   * Time/Frequency/Condition
   * Location
   * a section header
   * the previous accommodation block
4. Join title lines into a single normalized string.
5. Collapse duplicate whitespace.

The full Universal Tools title must be preserved.

---

# Fix 2: Remove IEP Boilerplate Language

## Current Problem

Descriptions contain repeated compliance language.

Example:

```text
The IEP Team must consider if this accommodation is required to participate in extracurricular and nonacademic activities.
```

This language appears repeatedly and provides no value to teachers.

## Required Behavior

Remove all occurrences of:

```text
The IEP Team must consider if this accommodation is required to participate in extracurricular and nonacademic activities.
```

Also remove partial fragments caused by line wrapping.

Examples:

```text
accommodation is required to participate in extracurricular and nonacademic activities
```

```text
required to participate in extracurricular and nonacademic activities
```

```text
participate in extracurricular and nonacademic activities
```

These should not appear in descriptions.

# Fix 3: Extract Location

## Current Problem

Location text is embedded inside descriptions.

Examples:

```text
General and Special Education
```

or

```text
General
and
Special
Education
```

## Required Behavior

Normalize and extract into:

```json
{
  "location": "General and Special Education"
}
```

Remove the location text from the description after extraction.

Do not leave location null when this text exists.

# Fix 4: Remove Footer/Header Contamination

## Current Problem

Some accommodation blocks contain footer text from the PDF.

Examples include:

```text
DOB:
```

```text
UIC:
```

```text
IEP Date:
```

```text
Operating District:
```

```text
Page
```

These lines should never be part of accommodation extraction.

## Required Behavior

Before parsing:

Remove any line containing:

* DOB:
* UIC:
* IEP Date:
* Operating District:
* Page

This filtering should occur before accommodation block construction.
